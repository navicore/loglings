# Hint — 03-standard-order

One goal: the two arguments with the `@`-prefixed "before" operator
between them. The `@` is what keeps it in the term world — the plain `<`
would try to compare arithmetically and reject the atoms and compounds
in the test.

If a case surprises you, name the *kind* of each side (number? atom?
compound?) and apply: Variables < Numbers < Atoms < Compounds.
