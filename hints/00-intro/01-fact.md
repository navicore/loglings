# Hint — 01-fact

A fact is exactly one line. It starts with a lowercase name (the *functor*),
has its arguments in parentheses (or none), and ends with a period.

You already have one example fact:

    cat(whiskers).

The exercise wants a fact named `fruit` that takes one argument `apple`.
Use the same shape.

## Solution sketch

Add a single line:

    fruit(apple).
